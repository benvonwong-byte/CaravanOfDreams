# Caravan of Dreams

Website for Caravan of Dreams, the East Village vegan restaurant and community event space. Built with Next.js, Tailwind CSS and Sanity CMS.

## Develop

```bash
npm install
cp .env.example .env.local   # optional: without Sanity credentials the site shows demo content
npm run dev                  # http://localhost:3000, Sanity Studio at /admin
```

Checks: `npm run lint`, `npm run typecheck`, `npm run build`.

Project conventions and code map are in [`CLAUDE.md`](CLAUDE.md).
